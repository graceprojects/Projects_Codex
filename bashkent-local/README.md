# HAVEN — локальная рабочая копия

## Запуск

Дважды нажмите `Start.command`, затем откройте http://localhost:8080 в браузере.
Окно терминала должно оставаться открытым. Для остановки нажмите Ctrl+C.
Если порт занят, возможно, копия уже запущена: откройте указанный адрес.

## Редактирование

Рабочие файлы находятся в `site/`:

- `index.html` — главная страница и окна выбора квартиры.
- `styles.css` — оформление и адаптация к размерам экрана.
- `script.js` — выбор корпусов, планировки, 3D, панорамы и AR.
- `map2d.js` — карта на главной странице.
- `map3d.html` и `map3d.js` — отдельная 3D-карта.
- `assets/` — изображения, видео, модели и данные.

После сохранения изменений обновите страницу (Cmd+R). Если браузер показывает старый вариант, используйте Cmd+Shift+R.

Это копия публичных файлов сайта http://159.89.93.31/site/, полученная 27 сентября 2026 года. Изменения здесь не изменяют сайт разработчика.
Сервер доступен только на этом компьютере. Внешний хостинг не нужен.
Для библиотек с CDN, Google Fonts и внешних сервисов нужен интернет. Это пока не полностью автономная офлайн-сборка.
Серверные исходники, база данных, исходные Blender/CAD-файлы и приватные интеграции не копируются с публичного сайта — их нужно отдельно получить у разработчика.
Запуск использует доступный в системе Python 3. На другом компьютере установите Python 3, если его ещё нет.

Главная страница и панель выбора корпуса/этажа открываются локально. Старые концептуальные планировки сохранены. Новый образец доступен отдельно: http://localhost:8080/apartment.html и через «Планировки» в меню главной.

## Планировки HAVEN · A3 / тип 44 — 2D / 3D

Откройте http://localhost:8080/apartment.html. Единое оформление — HAVEN 02 / Песок, без переключателя стилей. Старые параметры стиля в ссылке и сохранённые настройки не меняют оформление. Переключатель 2D / 3D находится справа от названия квартиры. В 3D подключена ранее подготовленная модель HAVEN 02 именно для A3 / типа 44.

В 3D доступны вращение, масштаб, вид сверху, исходный ракурс, мебель, выделение помещений и сохранение PNG. В 2D план всегда автоматически вписан в окно; ручной зум и перемещение отключены. Размеры доступны в 2D. Модель и локальный Three.js загружаются при первом открытии 3D. Высоты и отделка условные, стены в срезе на 1,10 м. Параметр `mode=3d` открывает объёмную модель сразу. Модуль: `site/haven44-3d.js`.

Переходы: комплекс → секция → квартира. На схеме доступны все 11 секций A/C; подробная квартира — трёхкомнатная A3 / тип 44 (проектное обозначение 2+1). Выбор этажей 2–7 использует общий типовой лист: номера отдельных квартир и данные о продаже не назначаются.

Инструменты: мебель, размеры, автоматическое вписывание, выделение комнат, разворот чертежа, избранное на этом компьютере, ссылка на текущий вид, экспорт SVG и печать/PDF. Клавиши M, D; 0 и +/− — только в 3D; Escape сворачивает чертёж.

Файлы страницы: `site/apartment.html`, `site/apartment.css`, `site/apartment.js`. Исходные векторы и контекст секций: `site/assets/plans/haven44/`. Для этой страницы внешние библиотеки и CDN не нужны.

`build_workbench_assets.py` воспроизводит подготовку данных из `output/plan-studies/a3-type44` и проектного PDF; нужны PyMuPDF и Shapely. Все 889 геометрических объектов квартиры сохранены из утверждённых вариантов. Общие контуры секций упрощены для навигации; детальные секции показывают архитектурные линии проектного листа. DWG-ревизия, север и инсоляция не сверены.

Площадь SAT.A в источнике — 91,63 м². Сумма подписей помещений с балконом — 92,46 м². Расхождение 0,83 м² сохранено в интерфейсе.

Проверки текущей версии описаны в `HAVEN44-QA.md`; автоматическая проверка — `test-haven44.mjs`. Старые `test-apartment.mjs` и `test-apartment-3d.mjs` относятся к предыдущему образцу, не к A3 / 44.

После правок обновите страницу (Cmd+R, при кэшировании — Cmd+Shift+R). Резервная копия перед этой переработкой: `../output/backups/apartment-before-haven44/`.
