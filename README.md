# DEVELOPERS TOOLS / HAVEN

Локальные рабочие материалы для сайта жилого комплекса HAVEN. Основная версия, которую мы редактируем и просматриваем на `localhost:8080`, находится в [`bashkent-local/site`](bashkent-local/site). Это статический сайт: для просмотра достаточно Python 3.

## Работа на другом компьютере

1. Склонируйте этот репозиторий.
2. Установите Python 3, если его ещё нет.
3. На macOS откройте `bashkent-local/Start.command` или выполните из корня репозитория:

   ```sh
   python3 -m http.server 8080 --bind 127.0.0.1 --directory bashkent-local/site
   ```

4. Откройте `http://localhost:8080/apartment.html` для раздела выбора квартиры или `http://localhost:8080/` для главной страницы.

Изменения файлов в `bashkent-local/site` станут видны после обновления страницы. Перед продолжением работы на другом компьютере получите последние коммиты Git; после работы отправьте свои коммиты в репозиторий.

## Структура

- `bashkent-local/` — текущая локальная версия сайта и её документация.
- `haven-site/` — предыдущий вариант оформления и выбора квартиры.
- `haven-picker/` — отдельные инструменты выбора квартиры и планы этажей.
- `plans-svg/` — SVG-проработки одной планировки.
- `output/plan-studies/` — варианты планировки HAVEN 02, модель 3D и проверки геометрии.
- `output/plan-layout-options/` — четыре варианта компоновки страницы.
- `output/apartment-sites-research-2026-09-28/` — исследование 50 сайтов девелоперов.

Репозиторий публичный. Крупные проектные чертежи, архивы, брендбук и локальные резервные копии в него не включены. Сайт содержит подготовленные изображения, схемы и планы, необходимые для текущей демонстрации; исходные CAD-файлы для повторной инженерной сверки остаются на исходном компьютере.

Локальный сервер использует адрес `127.0.0.1` и виден только на том компьютере, где он запущен. Текущая демонстрация не включает серверную часть сайта, базу данных или рабочую CRM-интеграцию.
